# Лабораторная работа №1 — вариант 6

**Тема:** Процессы и межпроцессное взаимодействие через каналы (`pipe`).

**Условие:** Родительская программа запрашивает имя файла и открывает его для чтения. Содержимое файла передаётся в стандартный ввод дочерней программы. В файле записаны строки с произвольным количеством целых чисел типа `int`. Дочерняя программа вычисляет сумму чисел каждой строки и выводит результаты в стандартный вывод, перенаправленный в канал (`pipe`). Родитель читает результаты из канала и выводит их в терминал. Родитель и ребёнок — отдельные программы.

## Компиляция и запуск (Linux)

```bash
gcc -Wall -Wextra parent.c -o parent
gcc -Wall -Wextra child.c -o child
./parent
```

После запуска введите путь к файлу с числами.
